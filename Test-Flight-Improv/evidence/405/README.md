## Toolchain note

The checkout was migrated to Flutter 3.47.2 (pubspec `flutter: '>=3.47.2'`,
`.dart_tool` generated by Dart 3.13.2) while the Mac's `PATH` still resolves
`flutter` to 3.41.4. Running the PATH SDK compiles 3.47.2 framework sources
with a 3.41.4 engine and dies inside `flutter/lib/src`. Every run here went
through `docker-ws/flutter_sdk.sh` / `docker-ws/dart_sdk.sh`, which exec the
3.47.2 SDK at `~/development/flutter-3.47.2`.

Two `unawaited_return_in_try_block` analyzer warnings
(`application_root.dart`, `conversation_wired.dart`) are pre-existing code
newly flagged by the 3.47.2 analyzer; both lines are untouched by this change.
