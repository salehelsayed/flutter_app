- `MknoonFirebaseMessagingService.onMessageReceived` routes through one pure
  classifier: fixed only when `notification == null` and the data map is

### One marker and one honest audible disposition

- `DroppedPushRecoveryStore` gained a strict trigger kind

  `UNSUPPORTED_PENDING` that never reads as no work and never authorizes

  Legacy records decode deletion/`true`; `DELETED_BATCH` commits `true` before
  its incumbent possibly-audible attempt; a new `FIXED_WAKE` commits `false`
  only when no current same-binding marker holds `true` — coalescing never
  downgrades an audible ambiguity. Marker/kind/disposition commit before
  notification or scheduling inside the store lock; exact ACK and binding
